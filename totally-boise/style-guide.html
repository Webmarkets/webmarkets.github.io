03

Using gold (without the mustard)

Gold reads as premium when it behaves like metal: thin, catching light, and rare. It reads as mustard when it's flat and everywhere. These rules keep it on the right side.

Do

  • Use the gradient for any gold element bigger than text.
  • Keep gold thin: 2–3px top borders, dividers, frames.
  • Reserve it for TB Gold moments: badges, featured listings, awards.
  • Pair gold with ink or emerald so it glows against something dark.
  • One gold element per screen is usually enough.

Don't

  • Fill large areas with flat #C9A14E — that's where mustard lives.
  • Put gold text on green, or green text on gold.
  • Use the old amber #FFB51E anywhere in the new brand.
  • Stack multiple gold buttons or badges in the same section.
  • Use gold for body text or long labels.
