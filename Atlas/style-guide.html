Design System · The Cartographer's Edition

Agency Atlas Style Guide

The visual language behind Agency Atlas: aged map paper, cartographer's ink, hard-stamp shadows, and editorial serif display type. Use this reference to keep every page on the same map.

Section 02

Typography

3 FAMILIES · GOOGLE FONTS
--font-display Fraunces
Aa Bb Cc 0123 &?!

Serif display face for all headings, quotes, and big numbers. Weights 400–900 plus italics. Italic 600 in vermilion or gold is the house emphasis style.

--font-body Archivo
Aa Bb Cc 0123 &?!

Sans-serif workhorse for body copy, buttons, and UI text. Weights 400–700. Body text sits at 14–18.5px with a 1.65 line height.

--font-mono Space Mono
Aa Bb Cc 0123 &?!

Monospace for eyebrows, labels, coordinates, nav links, and fine print. Almost always uppercase, bold, with wide letter-spacing (.1–.2em).

Section 03

Buttons & Shadows

STAMPED · HARD-EDGE

Every interactive element is "stamped": 2px ink border, zero border-radius, and a hard offset shadow. On hover, buttons press into the page — they translate toward the shadow and the shadow shrinks.

Section 05

Form Elements

SQUARE · STAMPED

Inputs are square-cornered cream fields with the standard 2px ink border. Labels are Space Mono uppercase. Focus is indicated by the small hard shadow — no glow, no outline color change.

Section 07

Contour Texture

.CONTOURS · PURE CSS

This section has the .contours class applied — look closely for the faint topographic rings. It's built from two repeating radial gradients at ~5% ink opacity, attached via a ::before pseudo-element so content stays untouched. Use on hero and light feature sections; a cream-toned variant appears inside the dark ticket component.
